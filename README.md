# 午後買い候補スクリーナー v0.1

完全無料・仮想取引の初期版です。

## 目的
毎営業日の12時ごろに、
「12:30以降にブレイク買いを狙う候補」を抽出し、

- 現在値
- VWAP
- 前場高値/安値
- スコア
- 逆指値価格
- 損切り価格
- 推奨株数

を出します。

**実際の注文は一切行いません。**

## 実行

```bash
pip install yfinance pandas numpy
python afternoon_screener.py
```

## 注意
- yfinanceの5分足データは取得可能期間や仕様が変わることがあります。
- これは検証開始用のv0.1です。
- スコアの重みはまだ最適化していません。
- 実運用へ移す前に、ウォークフォワード検証を行います。
